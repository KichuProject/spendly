Frequently Asked

Everything you need to know about setting up and running Spendly.

Is this APK safe to download and install?

Absolutely. The APK file is built directly from the React Native source code in this repository. Since it is side-loaded (not from the Google Play Store), your device may ask for confirmation to install from unknown sources. You can safely approve it.

How do push notifications work?

Spendly uses Expo Push Notifications integrated with a Node.js background scheduler. When you register or update your account, your device token is stored. The backend cron scheduler checks daily and pushes alerts to keep your ledgers sync'd.

Can I run this offline?

Yes, your profile and balances are cached locally. Once you reconnect to the internet, any pending offline transactions and balances will sync automatically with the MongoDB Atlas database cluster.

How do I test the backend API endpoints?

We have included a full set of developer routes. You can call GET /api/test/seed to automatically seed user files, transactions, and notification records to start testing immediately.
